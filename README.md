# 📈 Hệ Thống Khảo Sát Sự Biến Thiên Hàm Số Tự Động

**Hệ Thống Khảo Sát Sự Biến Thiên** là một ứng dụng web mã nguồn mở được xây dựng bằng **Python & Streamlit**. Ứng dụng tự động hóa toàn bộ quá trình khảo sát và vẽ đồ thị hàm số chuẩn theo chương trình Sách Giáo Khoa (SGK) Toán THPT. 

Đặc biệt, đây là công cụ đắc lực hỗ trợ giáo viên và học sinh soạn thảo tài liệu Toán học với tính năng **xuất mã LaTeX (TikZ & Tkz-tab)** chỉ bằng 1 cú click! 🚀
